## 二、训练参数优化

### 2.1 学习率调整

| 场景 | 推荐学习率 | 说明 |
|------|-----------|------|
| 当前（Adapter微调） | 5e-5 ~ 1e-4 | 适合冻结大部分参数的场景 |
| 微调BERT | 2e-5 ~ 3e-5 | BERT需要更小的学习率 |
| 全量微调 | 1e-5 ~ 2e-5 | 全量训练需要更小学习率 |

**建议**：
```python
train_model(
    learning_rate=5e-5,      # 降低学习率
    num_train_epochs=5,      # 增加训练轮数
    per_device_train_batch_size=4
)
```

### 2.2 批大小与梯度累积

**当前配置**：batch_size=2, gradient_accumulation=4（等效batch_size=8）

**优化方案**：
```python
# 方案1：增大实际batch size
train_model(
    per_device_train_batch_size=4,   # 提升到4
    gradient_accumulation_steps=2,   # 降低到2，等效batch=8
    ...
)

# 方案2：保持小batch但增加累积
train_model(
    per_device_train_batch_size=2,
    gradient_accumulation_steps=8,   # 增大到8，等效batch=16
    ...
)
```

**显存估算**：
- 16GB显存：支持 batch_size=2
- 24GB显存：支持 batch_size=4
- 48GB+显存：支持 batch_size=8

### 2.3 训练轮数

| 数据量 | 推荐轮数 | 说明 |
|--------|----------|------|
| <1万 | 5~10轮 | 小数据集需要更多轮次 |
| 1~5万 | 3~5轮 | 中等数据量 |
| >5万 | 2~3轮 | 大数据集不需要太多轮 |

### 2.4 优化器与调度器

**当前**：默认 AdamW + 线性衰减

**建议增加**：

## 三、模型架构改进

### 3.1 特征编码器增强

**NumericEncoder 改进**：
```python
# 当前：2层 MLP (9→128→128)
# 改进：更深的网络 + 残差连接

class EnhancedNumericEncoder(nn.Module):
    def __init__(self, input_dim=9):
        super().__init__()
        self.layer1 = nn.Linear(input_dim, 128)
        self.bn1 = nn.BatchNorm1d(128)
        self.layer2 = nn.Linear(128, 128)
        self.bn2 = nn.BatchNorm1d(128)
        self.layer3 = nn.Linear(128, 128)
        self.bn3 = nn.BatchNorm1d(128)
        self.output_layer = nn.Linear(128, 128)
        
    def forward(self, x):
        # 残差连接
        h = torch.relu(self.bn1(self.layer1(x)))
        h = h + torch.relu(self.bn2(self.layer2(h)))  # 残差
        h = h + torch.relu(self.bn3(self.layer3(h)))  # 残差
        return self.output_layer(h)
```

### 3.2 融合策略改进

**当前方案**：简单拼接 + 线性层

**改进方案1：注意力融合**
```python
class AttentionFusion(nn.Module):
    def __init__(self, numeric_dim=128, bert_dim=768):
        super().__init__()
        # 跨模态注意力
        self.numeric_to_bert_attn = nn.MultiheadAttention(
            embed_dim=numeric_dim, 
            num_heads=8,
            batch_first=True
        )
        self.bert_to_numeric_attn = nn.MultiheadAttention(
            embed_dim=bert_dim,
            num_heads=8,
            batch_first=True
        )
        # 门控融合
        self.gate = nn.Sequential(
            nn.Linear(numeric_dim + bert_dim, 256),
            nn.Sigmoid()
        )
    
    def forward(self, numeric, bert):
        # 注意力交互
        numeric_enhanced, _ = self.numeric_to_bert_attn(
            numeric.unsqueeze(1), bert.unsqueeze(1), bert.unsqueeze(1)
        )
        bert_enhanced, _ = self.bert_to_numeric_attn(
            bert.unsqueeze(1), numeric.unsqueeze(1), numeric.unsqueeze(1)
        )
        
        numeric_enhanced = numeric_enhanced.squeeze(1)
        bert_enhanced = bert_enhanced.squeeze(1)
        
        # 门控融合
        gate_weight = self.gate(torch.cat([numeric_enhanced, bert_enhanced], dim=1))
        fused = gate_weight * numeric_enhanced + (1 - gate_weight) * bert_enhanced
        
        return fused
```

**改进方案2：门控机制**
```python
class GatedFusion(nn.Module):
    def __init__(self, dim):
        super().__init__()
        self.gate_numeric = nn.Linear(dim, dim)
        self.gate_bert = nn.Linear(dim, dim)
        
    def forward(self, numeric, bert):
        gate = torch.sigmoid(self.gate_numeric(numeric) + self.gate_bert(bert))
        return gate * numeric + (1 - gate) * bert
```

```python
def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)
    probabilities = torch.softmax(logits, dim=-1)[:, 1]
    
    return {
        'accuracy': accuracy_score(labels, predictions),
        'precision': precision_score(labels, predictions),
        'recall': recall_score(labels, predictions),
        'f1': f1_score(labels, predictions),
```
