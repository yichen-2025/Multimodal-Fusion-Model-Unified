# 论文与开源项目极简指南

## 一、 论文核心要求（顶会级）

### 1. 必备实验清单（缺一不可）

- [ ] **对比实验**：与SOTA方法（如其他Transformer、MLP基线）对比。
- [ ] **消融实验**：逐个移除核心模块（如BERT、数值编码器、融合层），验证贡献。
- [ ] **重复实验**：至少3次不同随机种子的重复，报告均值±标准差。
- [ ] **可视化**：
    - 特征分布图（t-SNE/UMAP）
    - 混淆矩阵
    - 注意力/特征重要性热力图

### 2. 复现性保障

- [x] 固定所有 `random_seed`（随机种子）
- [x] 记录 `Hardware`（GPU型号、显存）和 `Time`（训练时长）
- [x] 提供 `requirements.txt`（锁定版本）和 `config.yaml`（超参数）

### 3. 论文结构（建议）

```text
1. Introduction (痛点、贡献)
2. Related Work (现有方法不足)
3. Methodology (模型架构图+公式)
4. Experiments (数据集、结果、消融、可视化)
5. Conclusion & Future Work
```

## 二、 开源项目必备要素

### 1. 项目结构（标准）

```
Multi-modal-model/
├── README.md          # 核心：项目介绍、安装、快速使用
├── LICENSE            # 必加：推荐 Apache 2.0 或 MIT
├── requirements.txt   # 依赖清单（需锁定版本）
├── setup.py           # 打包脚本
├── src/               # 核心代码（已有）
├── configs/           # 配置文件目录
│   └── config.yaml
└── scripts/           # 脚本目录
    ├── train.sh       # 训练脚本
    └── test.sh        # 测试脚本
```

### 2. README.md 必写内容

1. **简介**：一句话说明项目做什么。
2. **架构图**：直观展示模型结构。
3. **Installation**：一键安装命令。
4. **Quick Start**：最小可运行示例代码。
5. **Datasets**：数据集下载链接和格式说明。
6. **Performance**：与SOTA对比的表格。
7. **Citation**：BibTeX格式引用。

### 3. 代码质量

- **类型注解**：关键函数添加 `type hints`。
- **异常处理**：避免程序崩溃，增加错误提示。
- **日志系统**：统一日志输出（已有基础）。

## 三、 本项目优化路线图

### 第一阶段：完善实验（核心）
1. **补充消融实验**：
    - 仅用数值特征 vs 仅用文本特征 vs 融合特征。
    - 替换融合策略（Concat vs Attention）。
2. **跨数据集验证**：至少在 2 个数据集（如 CICIDS2017）上测试。
3. **添加可视化**：生成特征分布图和混淆矩阵图。

### 第二阶段：工程化改造
1. **配置文件**：将硬编码参数迁移至 `config.yaml`。
2. **脚本封装**：编写 `train.sh` 简化运行流程。
3. **文档完善**：按照上述模板重写 `README.md`。

### 第三阶段：开源发布
1. **许可证**：添加 `Apache 2.0 License`。
2. **模型发布**：将训练好的权重上传至 Hugging Face 或 Zenodo。
3. **代码清理**：删除调试代码和临时文件。
4. **发布预印本**：提交至 arXiv。
